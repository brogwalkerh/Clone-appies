# Messages Evidence Exporter (planning)

A native macOS app, command-line tool, and independent verifier for exporting iMessage / SMS history from the macOS Messages app in a form that can be authenticated and received in evidence in California courts.

Nothing is built yet. Start with:

* [`PLAN.md`](PLAN.md) — product and engineering plan, phases, architecture, testing.
* [`docs/legal-requirements-california.md`](docs/legal-requirements-california.md) — the California evidence rules, case law, privacy statutes, and court-format rules the design is derived from, with traceable requirement IDs.

This project does not give legal advice. Licensed under GPL-3.0.
